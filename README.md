# Application-of-Pertubation-theory-via-the-Helium-Atom
BACKGROUND:

In physics we there is a principle in which systems with three different things applying force on one and other cannot be solved, but in using advanced theory we can approximate and get very close to the actual values that experiment produces.

One of the failures of early quantum theory like the Bohr Model of the Atom was that for non-hydrogenic systems (ie atoms with only one electron being attracted by the nucleus) theoretical values for energy states and diverged greatly from experiment.

But when Erwin Schrodinger introduced the his quantum mechanical wave equation in the year 1926 physicists were able to now properly model these advanced systems. Though not exactly solvable physicists from as early as 1929 were able to get almost exact approximations of the energies of the Helium Atom via using new mathematical methods on top of Schrodingers wave mechanics which became one of the great victories that solidified the Schrodinger wave equation as the fundamental equation of quantum mechanics.
